# PictoAgenda

Agenda visual con pictogramas de ARASAAC, fotos propias y dictado por voz. Es una web estática (PWA), así que no necesita compilación.

- Los datos (fotos, elecciones, rutinas) se guardan solo en cada móvil.
- El perfil personal no está en este repositorio: se importa desde la app.

Pictogramas: Sergio Palao. Origen: ARASAAC (https://arasaac.org). Licencia CC BY-NC-SA. Propiedad: Gobierno de Aragón (España).
